# Расширение банка вопросов

Генератор формирует вопросы из актуальных версий фактов проекта. Число вопросов не фиксируется: доступны все опубликованные пригодные факты, а лимит проекта в админке ограничивает назначение на одну попытку.

## Дополнительные автоматически проверяемые темы

- Каталог хранит цену «от» и минимальную площадь отдельно для каждого типа квартир. Для комнатной цены вопрос указывает тип жилья, комнатность, дату снимка и предупреждение, что применимость акций не подтверждена каталогом. Такая цена не трактуется как максимум или полный диапазон.
- Детальная страница проекта даёт структурированные проектные метрики: площадь участка, число очередей, секций и мест в школе/детских садах, а также площадь благоустройства. Они сохраняются как отдельные подтверждённые числовые факты с исходным фрагментом.
- Уже поддерживаемые поля площади, этажности, сроков по корпусам и транспортной доступности сохраняют проектную область, тип поездки и срок актуальности. Вопросы возникают только когда есть три уникальных сопоставимых значения из других проектов.
- Отделка, планировочные особенности, описание дворов, архитектуры, парковки и рекламные преимущества остаются кандидатами на ручную проверку, пока источник не даёт однозначного одиночного значения. Отсутствие упоминания не становится ответом «нет».

Полная максимальная стоимость не выводится из цены «от». Для неё нужен разрешённый и полный обход одного типа недвижимости с одинаковыми условиями оплаты; пока источник такого подтверждения не даёт, ценовые вопросы о максимуме не публикуются.

## Буклеты

Сборщик может взять только ссылку на PDF, явно опубликованную на странице этого проекта, и только с наблюдаемого домена CMS GloraX. До загрузки проверяется `robots.txt`; авторизация, антибот-защита, неизвестный домен и запрещённые пути не обходятся. Ограничения: 30 MiB на PDF, 300 страниц и 1,5 млн символов текста; на один запуск — до 256 MiB PDF. Извлечённый текст сохраняется как исходный материал с номерами страниц и хешем PDF. Он не становится подтверждённым фактом и не участвует в генерации до ручной проверки. Для сканированных страниц OCR не выполняется; в отчёте будет `no_text_layer`.

Администратор открывает проект → «Исходные материалы проекта» → PDF-материал. Из его фрагмента можно добавить отдельный факт в карточке проекта с нужным ключом, единицей, областью, условиями и ссылкой на буклет/страницу, затем проверить и сохранить его. Только однозначные scalar-факты с доказуемыми отвлекающими вариантами попадают в автоматический банк. Экспертные оценки и формулировки на основе маркетингового описания проходят ручную проверку вопроса.

Число вопросов в проекте меняется после успешного сбора и публикации нового снимка данных. Повторные версии фактов не переписывают историю уже завершённых попыток.
